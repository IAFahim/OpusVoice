OpusVoice QR Console

What is this?

The web twin of the Android app's QR system: scan a code, get typed data.

  • pinhole1:… — a Pinhole connection-string ticket
  • udp://host:port — a plain RTP target
  • anything else is shown as raw text — nothing is silently lost

Scanning runs entirely on-device: the camera feed never leaves this page. Installable as a PWA.

Stream live Opus voice to the receiver — the same RTP stream the Android app sends, over a WebSocket the browser is allowed to open.

Start one with dotnet run --project src/OpusVoice.Receiver -- ws 8080 — it prints a ws:// QR next to the usual udp:// one. Browser rule: from this https page only ws://localhost is reachable; for LAN IPs run the console locally (npm run dev).
